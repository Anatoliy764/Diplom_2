# Дипломная работа

## Задание 2: API

# Описание проекта: **Diplom_2**

Этот проект создан для тестирования REST API сервиса **Stellar Burgers**. Основная цель — обеспечить качество работы API методом автоматизированного тестирования. В проекте реализованы покрытия для всех критически важных API-методов, описанных в задании.

## Задачи проекта:
Проверка работы следующих функциональностей сервиса Stellar Burgers:
1. **Создание пользователя**:
   - Создание уникального пользователя;
   - Попытка создания уже зарегистрированного пользователя;
   - Попытка создания пользователя с пропуском обязательных полей.

2. **Логин пользователя**:
   - Успешный вход с корректными данными;
   - Попытка входа с некорректным логином и/или паролем.

3. **Обновление данных пользователя**:
   - Обновление данных с авторизацией;
   - Попытка обновления данных без авторизации (с проверкой корректности ошибок).
   - Проверка изменений всех полей (email, password, name).

4. **Создание заказа**:
   - Создание заказа авторизованным пользователем;
   - Попытка создания заказа без авторизации;
   - Создание заказа с корректными ингредиентами;
   - Попытка создания заказа без ингредиентов;
   - Попытка создания заказа с неверными хэшами ингредиентов.

5. **Получение заказов пользователя**:
   - Успешное получение заказов авторизованным пользователем;
   - Попытка получения заказов без авторизации.

## Особенности реализации:
- Написание тестов основано на предоставленной документации для API сервиса Stellar Burgers.
- В каждом тесте проверяется:
   - Код ответа сервера (HTTP Status);
   - Ответное сообщение сервиса (response body);
   - Соответствие полей ожидаемым значениям при авторизации и работе с заказами, пользователями.

- Все тесты являются полностью независимыми благодаря реализации автосоздания и удаления тестовых данных.

## Структура проекта:
1. **Классы тестов**: Для каждой группы методов API (например, создание пользователя, логин, заказы) реализован отдельный тестовый класс. В проекте представлены основные классы:
   - — тесты для создания пользователей. `UserCreateTest`
   - — тесты для изменения данных пользователей. `UserUpdateTest`
   - — тесты для работы с заказами (создание, получение). `CreateOrderTest`

2. **Аннотации тестов**:
   - В каждом тесте используются стандартные аннотации JUnit (`@Test`, `@BeforeEach`, `@AfterEach` и параметризованные тесты с `@ParameterizedTest` и `@MethodSource`).
   - Для сохранения контекста тестов добавлены аннотации Allure: `@Step`, `@DisplayName`, `@Description`.

## Настройка проекта

### Предварительные требования:
- Установленный **Java JDK 11+**;
- Установленный и настроенный **Maven**;
- Установленный Allure для генерации отчётов:
```bash
   brew install allure
```         

## Как запустить тесты

Для запуска тестов и создания отчетов о тестировании выполните следующую команду в терминале:

```bash
mvn clean test -fn -X -e 
```

## Как посмотреть отчеты

Для просмотра отчетов выполните в терминале команду:
```bash
 allure serve target/surefire-reports/
```
